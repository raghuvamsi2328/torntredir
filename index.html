Architecture

Swarm Engine
Direct WebRTC peer connections eliminate central proxy bottlenecks. Files are requested block-by-block and stored in IndexedDB temporary buffers.
Media Inspection
Header frames are read selectively first. Streamable containers (.mp4, .mkv, .mp3) play immediately while remaining blocks load in the background.
Local Privacy
Zero server uploads. Magnet metadata and file structures are calculated locally using WebAssembly rust-bencode modules.
